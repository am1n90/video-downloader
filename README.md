# Video Downloader

Десктопное приложение для Windows для скачивания видео и аудио с
YouTube, VK, TikTok, Instagram и других площадок, поддерживаемых
[yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Возможности

- Скачивание видео (с выбором качества) и аудио (MP3) по ссылке.
- Очередь загрузок: несколько ссылок одновременно, пауза и докачка
  прерванной загрузки.
- Скачивание фрагмента видео вместо целого файла — ползунок с двумя
  ручками, точный тайм-код (мм:сс / ч:мм:сс), предпросмотр кадра.
- Библиотека — история всех скачанных файлов с быстрым доступом и
  удалением записей (по желанию — вместе с файлом на диске).
- Автоматическая проверка и установка обновлений с GitHub Releases.
- Fluent Design интерфейс, светлая и тёмная темы.

## Установка

1. Откройте страницу [Releases](https://github.com/am1n90/video-downloader/releases/latest)
   и скачайте последний `VideoDownloader-Setup-<версия>.exe`.
2. Запустите установщик. Он ставит программу для текущего пользователя
   (без прав администратора), в меню Пуск и на рабочий стол
   добавляются ярлыки.

### Предупреждение SmartScreen

Установщик не подписан цифровой подписью (сертификат подписи кода —
платный, для проекта такого масштаба нецелесообразен), поэтому при
запуске Windows может показать:

> «Windows защитила ваш компьютер» — Microsoft Defender SmartScreen
> предотвратил запуск неизвестного приложения.

Это ожидаемо для любого неподписанного установщика и не означает, что
файл заражён. Чтобы продолжить:

1. Нажмите **«Подробнее»**.
2. Нажмите **«Выполнить в любом случае»**.

Если вы хотите убедиться в целостности скачанного файла — на странице
релиза рядом с установщиком выложен `latest.json` с его SHA-256;
приложение сверяет такую же сумму автоматически при обновлении.

## Как пользоваться

1. Вставьте ссылку на видео в поле на главной странице и нажмите
   «Анализ» — появится превью и список доступных качеств/форматов.
2. Выберите качество видео или аудио (MP3) и нажмите «Скачать».
3. Чтобы скачать только часть видео — включите галочку «Скачать
   только фрагмент», задайте начало и конец ползунком или полями
   времени.
4. Во время загрузки можно поставить её на паузу и продолжить позже —
   докачка происходит с того же места.
5. Все завершённые загрузки видны на странице «Библиотека»: оттуда
   можно открыть файл, его папку или удалить запись (и, по желанию,
   сам файл).
6. Папка загрузок, тема и параллельность загрузок настраиваются на
   странице «Настройки». Там же — проверка обновлений.

## Системные требования

- Windows 10 или новее, 64-разрядная система.
- Доступ в интернет.
- Права администратора не нужны — установка идёт в профиль текущего
  пользователя.
